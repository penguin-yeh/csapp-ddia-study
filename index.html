    為什麼這樣排

    先 CSAPP、再 DDIA，不交錯。CSAPP 的行程、記憶體、網路、並行是 DDIA 的地基；Proxy Lab 寫完再進分散式，6.5840 的 RPC 和並行 bug 會好懂很多。兩本同時讀，每週 8–10 小時會被切得太碎。

    階段期間週數主軸
    CSAPP2026/11/02 – 2027/02/0714Data → Bomb → Attack → Cache → Shell → Malloc → Proxy
    DDIA 2e2027/02/08 – 2027/05/3016Gossip Glomers 暖身 → MapReduce → KV → Raft → KV Raft

    CSAPP Ch4（處理器架構）先略過，對後端面試幫助小；Ch5、Ch7 以速讀為主。6.5840 用 Go，所以第 14 週安排 Go 暖身。Raft（W24–W27）是整份計畫最難的段落，時間不夠就讓它延一兩週，不要硬趕。

    第一階段：CS:APP 第 3 版，Labs 用官網的 Self-Study Handout。第二階段：章名依 O'Reilly 第二版目錄（2026 年出版，共 14 章）；6.5840 Lab 編號依 Spring 2026 課表。

    每週節奏

    1. 週一到週三 · 閱讀（約 3 小時）：讀當週章節，做書裡的 practice problems，不要只看。
    2. 週四到週五 · Lab（約 3–4 小時）：做當週的 Lab 段落，卡住先自己 debug 30 分鐘再查資料。
    3. 週六 · 小專案（約 2 小時）：做當週的「小東西」，程式碼推上 GitHub。
    4. 週日 · 筆記（約 1 小時）：回答當週的筆記題目，用自己的話寫，講不清楚的地方就是還沒懂。

    面試準備軌道

    跟 30 週主線並行，每週多 3–4 小時（例如兩個平日晚上，或週末一個時段）。演算法從 W1 開始，系統設計從 W20 加入，行為面試從 W24 加入，W28–W30 用 45 分鐘計時 mock 收尾。

    項目期間內容
    演算法W1–W29NeetCode 150 依主題刷（18 個主題、150 題），每週 4–7 題；Bit Manipulation 提前到 W2 配 Data Lab
    系統設計W20–W30每週一題，對應當週 DDIA 章節，計時 45 分鐘出聲練

    計時 mockW28–W3045 分鐘模擬面試：演算法、系統設計、behavioral
    1. 平日晚上 ×2 · 演算法（約 2–2.5 小時）：每題先自己想 20–25 分鐘，想不出來再看 NeetCode 解說影片；隔幾天不看答案重寫一次。
    2. 週末 · 系統設計（W20 起，約 1 小時）：計時 45 分鐘、出聲講：需求與規模估算 → API → 資料模型 → 高階架構 → 深挖瓶頸與取捨，講完對照當週 DDIA 章節補洞。
    3. 週末 · 行為面試（W24 起，約 30 分鐘）：用 STAR（Situation、Task、Action、Result）寫 1–2 個故事，標出對應的 Leadership Principles，Result 盡量有數字。

    題數依 neetcode.io 上 NeetCode 150 的主題分組（2026/10/30 查）。忙的週先保 Lab，面試題可以順延。
