## ③ 動手

### 🧪 Lab
**Data Lab：整數題（bitXor、isTmax、conditional 等）**

- 下載 datalab-handout.tar，`make`，讀 `bits.c` 開頭的 coding rules
- 整數題：bitXor、tmin、isTmax、allOddBits、negate、isAsciiDigit、conditional、isLessOrEqual、logicalNeg、howManyBits（題名依 handout 為準）
- 每題做完跑 `./btest -f <題名>`；隨時用 `./dlc bits.c` 檢查是否違規、`./dlc -e bits.c` 看運算子數

### 🛠 小專案規格

**寫一個 `popcount` / `bitcount` 小工具，配單元測試涵蓋邊界值**

- **目標**：用 C 寫一個 popcount 工具，比較三種演算法並用測試鎖住邊界值。
- **功能需求**：
  - 實作 `popcount_naive`（逐位元）、`popcount_kernighan`（`x &= x-1`）、`popcount_swar`（分組相加，不用迴圈）
  - CLI 讀十進位或 0x 十六進位的 32-bit unsigned，印出三種結果
  - `make test` 跑單元測試；`make bench` 對 10^7 個隨機數計時
- **介面**：

```
$ ./popcount 0xF0F0
8 8 8
$ ./popcount 4294967295
32 32 32

unsigned popcount_naive(uint32_t x);
unsigned popcount_kernighan(uint32_t x);
unsigned popcount_swar(uint32_t x);
```

- **測試與驗收標準**：
  - 測試涵蓋 0、1、0x80000000、0xFFFFFFFF、0x55555555（=16）、0xAAAAAAAA（=16）
  - 對 10^6 個隨機數，三種實作結果與 `__builtin_popcount` 完全一致
  - `gcc -Wall -Wextra -O2` 零警告
  - bench 輸出三種實作的 ns/op
- **加分挑戰**：
  - 加 64-bit 版
  - 用 `objdump -d` 看 `__builtin_popcount` 在 `-mpopcnt` 下是否變成單一指令
- **預估時間**：2 小時
- **建議資料夾**：`csapp-labs/datalab/popcount/`
