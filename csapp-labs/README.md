# csapp-labs

CS:APP 第 3 版官方 Labs（第一階段 W1–W13）。每個 Lab 一個資料夾，放自己寫的程式、測試與心得。

- 官方 handout：https://csapp.cs.cmu.edu/3e/labs.html（下載 Self-Study Handout）

| 資料夾 | Lab | 週次 |
| --- | --- | --- |
| `datalab/` | Data Lab | W1–W2 |
| `bomblab/` | Bomb Lab | W3–W4 |
| `attacklab/` | Attack Lab | W5 |
| `cachelab/` | Cache Lab | W6–W7 |
| `shelllab/` | Shell Lab | W8–W9 |
| `malloclab/` | Malloc Lab | W10–W11 |
| `proxylab/` | Proxy Lab | W12–W13 |

> 註：CMU 請修課學生不要公開張貼 Lab 解答。可以考慮把完整解答放在私人 repo，這裡只放筆記、心得與自己寫的工具程式。
